# Funcionalidades

## Seções do site

### 1. Início (Hero)
- Nome "Isabella" em destaque.
- Identificação: Estudante de Desenvolvimento de Sistemas.
- Frase: "Transformando ideias em projetos por meio da tecnologia."
- Botão "Ver meus projetos".
- Elemento abstrato giratório ao fundo.

### 2. Sobre mim
- Apresentação pessoal.
- Informações acadêmicas.
- Layout moderno e organizado.

### 3. Projetos
- Galeria de projetos em cartões.
- Imagem, título, descrição e tecnologias utilizadas.
- Link para GitHub quando disponível.
- Não inventar projetos.

### 4. Contato
- Informações de contato fornecidas pela usuária.
- Links para redes profissionais.
- Formulário com validação dos campos.
- Mensagem de confirmação após preenchimento.
- Não simular envio real sem backend.

### 5. Rodapé
- Créditos.
- Links de navegação.
- Informações relevantes.

## Animações e interações

- Animações suaves durante rolagem (scroll reveal).
- Elemento abstrato giratório na tela inicial.
- Triângulos geométricos animados conforme rolagem.
- Transições suaves entre seções.
- Efeitos discretos em botões e cartões.
- Menu responsivo para dispositivos móveis.
- Alternância funcional entre modo escuro e modo claro.
- Escolha de tema salva no localStorage.
- Respeitar prefers-reduced-motion.
