# AGENTS.md — Regras do Projeto

## Objetivo

Portfólio pessoal completo para Isabella, estudante de Desenvolvimento de Sistemas.

## Regras gerais

- Utilizar apenas HTML, CSS e JavaScript puro.
- Não utilizar React, Bootstrap ou outros frameworks.
- Manter HTML semântico, CSS organizado e JavaScript separado.
- Não inventar informações pessoais, experiências, projetos ou links.
- Não substituir as referências visuais por um template genérico.
- Não alterar a identidade visual definida nos arquivos.
- Não utilizar azul como cor de destaque.
- Manter o rosa e o vermelho como cores principais da identidade.
- Não adicionar figurinhas ou adesivos decorativos.
- Não remover funcionalidades para simplificar o desenvolvimento.
- Preservar a organização dos arquivos.

## Estrutura de arquivos

```
portfolio/
├── AGENTS.md
├── referencias.md
├── identidade.md
├── funcionalidades.md
├── index.html
├── style.css
└── script.js
```

## Responsividade

O site deve funcionar em computadores, notebooks, tablets e celulares.

## Acessibilidade

Respeitar preferência por movimento reduzido (prefers-reduced-motion).
Evitar animações pesadas.
